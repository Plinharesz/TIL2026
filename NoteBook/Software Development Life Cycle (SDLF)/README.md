# Software Development Life Cycle
To a program be developed with majority quality, it needs to go through well defined stages, called by Software Development Life Cycle:

## 1- Requirement Analysis
Understand the problem and define what the software needs to do.
## 2- Design and Architecture
Draw the technical structure, the visual interface (UI) and User Experience (UX).
## 3- Development (coding)
Write the real code using programming language.
## 4- Tests (QA) 
Validate if the system works without errors (bugs) and check if it meets the initial requirements.
## 5- Implementation (Deploy)
Deploy the software
